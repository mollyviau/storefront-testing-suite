# storefront-testing-suite

## Overview

Storefront Testing Suite is a software testing capstone project focused on evaluating the quality and reliability of the Saleor open-source e-commerce platform.

The project applies software testing principles to validate critical business workflows using both manual and automated testing techniques.

---

## Project Objectives

- Plan a realistic software testing strategy.
- Design and execute manual test cases.
- Identify and document software defects.
- Perform UI and API testing.
- Track testing activities using Azure DevOps.
- Present testing results and recommendations.

---

## Application Under Test

**Application:** Saleor

Saleor is an open-source headless e-commerce platform that provides product management, shopping cart functionality, secure checkout, user accounts, and order management.

---

## Selected Workflows

The project focuses on testing the following critical workflows:

- Product Browsing
- Cart Management
- Checkout
- Order Tracking
- User Account Management
